# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be kind, assume good faith, and credit other people's work, including the Pinterest creators whose pins inspire yours.

Report unacceptable behaviour through a [private advisory](https://github.com/prantikmedhi/pinmuse/security/advisories/new)
or to the maintainer on GitHub (@prantikmedhi).
