# Security policy

pinmuse reads public Pinterest pages and calls the image APIs you configure with your own keys. Keys are read
from the environment or `~/.config/pinmuse/config.json` and are never written to output folders or manifests.

To report a vulnerability, open a [private security advisory](https://github.com/prantikmedhi/pinmuse/security/advisories/new)
rather than a public issue. You'll get a reply within a week.
